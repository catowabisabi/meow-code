## Task: Provider Heartbeat WebUI — SettingsPage Timeline Chart

### Objective
Update the SettingsPage providers tab to show provider heartbeat data from GET /api/providers/heartbeat as a mini timeline chart instead of just a colored dot.

### Context
The backend now exposes GET /api/providers/heartbeat which returns:
```
{
  "providers": [
    {
      "provider_id": "anthropic",
      "latency_samples": [245, 312, 289, ...],  // last 60 samples in ms
      "circuit_state_history": [{timestamp, from_state, to_state}, ...],
      "failure_timestamps": [1716460800.5, ...],
      "custom_thresholds": {"latency_ms": 2000, "failure_count": 5}
    }
  ],
  "server_time": 1716464400.0
}
```

### Requirements

**1. Update SettingsPage providers tab** (webui/client/src/pages/SettingsPage.tsx):
The providers section currently shows a simple status dot per provider. Replace with:

**2. Fetch heartbeat data**:
On mount, call GET /api/providers/heartbeat. Store in a local state or dedicated Zustand store (e.g., useProviderHeartbeatStore).

**3. Render mini sparkline chart per provider**:
For each provider, show a sparkline bar chart of latency_samples (last 60 points):
- X-axis: time (implicit — samples are sequential, oldest on left)
- Y-axis: latency in ms
- Bar color gradient: green (under threshold) → yellow (near threshold) → red (over threshold)
- Use custom_thresholds.latency_ms to determine coloring
- Show threshold line as a subtle horizontal dashed line at custom_thresholds.latency_ms
- If latency_samples is empty, show flat line at 0

**4. Show circuit state bands**:
Below or overlaid on the sparkline, show circuit state color bands from circuit_state_history:
- closed: green band
- half_open: yellow band
- open: red band

**5. Display additional info**:
- Provider name
- Last 5 failure timestamps as small dots (if any)
- Current circuit state indicator dot

**6. Implementation notes**:
- Use SVG or Canvas for the sparkline (no external charting lib needed for simple sparkline)
- Sparkline dimensions: approximately 200px wide, 40px tall
- Update heartbeat every 30 seconds via polling or useWebSocket for live updates
- Handle the case where /api/providers/heartbeat returns empty providers list gracefully
