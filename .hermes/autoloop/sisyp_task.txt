### Step 2: Fix IntrospectionPanel idle timeout bug
In webui/client/src/components/IntrospectionPanel.tsx:
- The idleTimer uses lastActivity to reset, but lastActivity updates on EVERY store action (setUsage, appendThinking, etc.)
- This means the panel never collapses because lastActivity keeps getting renewed even during tool-use
- Fix: track idle state separately — set idleStartTimestamp when status becomes 'idle', use that for the 5s timeout instead of lastActivity
- OR: only reset the idle timer when status transitions TO idle, not on every activity

```typescript
// Buggy current logic:
useEffect(() => {
  if (status === 'idle') {
    idleTimerRef.current = setTimeout(() => { setCollapsed(true); setExpanded(false) }, IDLE_TIMEOUT_MS)
  } else {
    setCollapsed(false)
    if (idleTimerRef.current) { clearTimeout(idleTimerRef.current); idleTimerRef.current = null }
  }
}, [status, lastActivity])  // ← lastActivity resets timer on every store update
```

```typescript
// Fixed: use a dedicated idleStart timestamp
const idleStartRef = useRef<number | null>(null)

useEffect(() => {
  if (status === 'idle' && !idleStartRef.current) {
    idleStartRef.current = Date.now()
    idleTimerRef.current = setTimeout(() => {
      setCollapsed(true); setExpanded(false)
      idleStartRef.current = null
    }, IDLE_TIMEOUT_MS)
  } else if (status !== 'idle') {
    idleStartRef.current = null
    if (idleTimerRef.current) { clearTimeout(idleTimerRef.current); idleTimerRef.current = null }
    setCollapsed(false)
  }
}, [status])
```
